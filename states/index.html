Ayuda de State Machine Simulator

Esta aplicación te permite diseñar, visualizar y simular el flujo lógico de autómatas de estados finitos utilizando Markdown jerárquico.

Formato del Editor

  • Línea de Transición: Escribila usando una flecha -> y dos puntos : para el trigger:
    - EstadoOrigen -> EstadoDestino : NombreEvento
  • Estado Inicial: El primer estado que se defina en el archivo se marcará automáticamente como el estado de inicio.
  • Estado Final / Aceptación: Si el nombre del estado termina con un asterisco (ej. Bloqueado*), se dibujará con doble anillo indicando que es un estado final.

Ejemplo:

- Cerrado -> Abierto : presionar_boton
- Abierto -> Cerrado : tiempo_limite
- Abierto -> Alarma* : vandalismo

Simulación Interactiva

  • Doble Clic: Define un estado como activo de forma manual en cualquier momento.
  • Panel de Disparadores: Hacé clic en los botones del panel lateral izquierdo para simular inputs. Si el estado activo tiene una transición vinculada a ese trigger, cambiará de estado.
  • Animación de Partículas: Al cambiar de estado por un trigger, verás una pequeña partícula brillante viajando por la flecha de transición hacia el nuevo nodo activo.
  • Lienzo Draggable: Podés acomodar los nodos circulares arrastrándolos con el cursor. Sus posiciones se guardarán en este navegador.
