**Arrastrar**: Haz clic en cualquier concepto y arrástralo libremente para cambiar su distribución temporal.

**Fijar concepto**: Haz **doble clic** en cualquier concepto para fijar su posición en la pantalla (las físicas dejarán de afectarlo a él de forma individual). Haz doble clic de nuevo para soltarlo.

**Zoom**: Desliza la rueda del ratón o haz zoom con gestos táctiles de pinza para alejar o acercar el mapa mental.

Guía completa de mapas mentales

Filosofía del creador de mapas

Crea mapas mentales interactivos y redes dinámicas con simulación física y múltiples orientaciones en vivo. Puedes redactar tus mapas usando dos métodos muy simples:

Método 1: Esquema Simple (Outline)

Es el más rápido. Funciona igual que Markmap. Escribe un título principal precedido por # y haz una lista estructurada con sangrías usando guiones:

# Cerebro Humano 🧠
- Lóbulo Frontal
  - Córtex Prefrontal
  - Funciones Ejecutivas
- Lóbulo Temporal
  - Hipocampo

Método 2: Red Avanzada (Conexiones)

Úsalo para crear flujos con conexiones cruzadas complejas, asignando formas, tamaños, estilos y colores personalizados a nodos y conectores:

# Circuito de Dopamina ⚡
## Nodos
- [vta] Área Tegmental Ventral (shape: circle, color: #3b82f6, size: 26)
- [accumbens] Núcleo Accumbens (shape: box, color: #ec4899)
- [dopamina] Liberación de Dopamina (color: #f59e0b)

## Conexiones
- vta -> accumbens (label: "Vía Mesolímbica", style: solid, color: #f472b6)
- accumbens -> dopamina (label: "Placer", style: dashed)

Atributos disponibles:

  • Nodos: shape: [circle, box, database, ellipse], color: [hex], size: [número].
  • Conexiones: label: "texto", style: [solid, dashed, dotted], color: [hex].
