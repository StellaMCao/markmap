Ayuda de ERD Database Studio

Esta aplicación te permite diseñar esquemas relacionales escribiendo Markdown y exportar el código SQL DDL correspondiente.

Formato del Editor

  • Tablas: Declaralas escribiendo ## NombreTabla.
  • Columnas: Listalas abajo con un guion - nombre_columna tipo_dato [atributos].
  • Llaves Primarias (PK): Agregá PK al final de la columna.
  • Llaves Foráneas (FK): Agregá FK -> NombreTablaPadre.columna_padre al final.

Ejemplo:

## clientes
- id int PK
- nombre varchar(100)
- email varchar(150)

## pedidos
- id int PK
- cliente_id int FK -> clientes.id
- total decimal(10,2)

Conectores "Pata de Gallo" (Crow's Foot)

El sistema detecta automáticamente las llaves foráneas y dibuja líneas conectoras inteligentes. El extremo que apunta a la llave primaria tiene el símbolo de Uno (||), mientras que el extremo de la llave foránea tiene la Pata de Gallo (Many >|) indicando una relación de Uno a Muchos.
