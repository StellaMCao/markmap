Ayuda de Markmap REPL Pro

Estructura y Niveles

-1 abre todas las ramas. 0 muestra únicamente el título. Elige otros números para controlar qué tan profundo se despliega inicialmente el mapa.

Interactividad de Ramas

En Forzar nivel, al presionar botones de nivel se reinicia el mapa. En Recordar ramas, los círculos conservan tus aperturas manuales. Clic en círculos abre/cierra; Ctrl+Clic aplica a toda esa rama.

Modos de Visualización

Oculta el editor para enfocarte solo en el mapa. El modo Lectura oculta el editor para una lectura limpia, y el modo Presentación oculta todos los paneles para proyectar tu mapa conceptual.

Búsqueda en el Mapa

Resalta coincidencias visibles. Si un nodo está en una rama contraída, no se marcará; despliega primero las ramas o haz clic en Abrir todo para buscar en todo el mapa.

Presets y Diseños

Los presets son combinaciones automáticas de fuentes, colores y espaciados diseñados con criterios ergonómicos. Aplica uno y ajústalo luego a tu gusto.

Imágenes, Audios y Tablas

Puedes insertar imágenes usando URLs públicas o compartidas de Google Drive. También puedes insertar un reproductor de audio, o usar el asistente para insertar tablas Markdown de cualquier tamaño.

Atajos de Teclado

Ctrl + Z Deshacer / Ctrl + Y Rehacer
Ctrl + S Descargar archivo Markdown (.md)
Ctrl + O Abrir/Importar archivo Markdown
Alt + P Alternar Modo Presentación (ESC para salir)
Alt + F Enfocar buscador del mapa

Funciones Avanzadas (Pro)

Foco Bidireccional: Doble clic sobre cualquier nodo del mapa mental para centrar y resaltar su línea en el editor. Arrastrar y Soltar: Arrastra un archivo .md o .txt de tu PC al editor para cargarlo al instante. Papelera: Vaciado rápido de editor.
